# ALEF Audio

Recorded clips for the ALEF Hebrew course: the man's Israeli voice and both English voices. The app plays them from this
repository's GitHub Pages address. The files are copies of `audio/m/israeli/` and `audio/<voice>/english/` in the ALEF
repository, placed here because one GitHub Pages site may hold at most 1 GB. Nothing here is edited by hand.

## Project structure

```text
alef-audio/
├── audio/      # Man's Israeli voice and both English voices
│   ├── f/      # 187 files
│   └── m/      # 15636 files
├── .nojekyll
├── index.html  # Pages landing file
└── README.md   # This file
```
